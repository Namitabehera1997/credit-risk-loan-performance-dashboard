# Retail Banking Credit Risk Analytics & Loan Performance Dashboard

## Project Overview
This project analyzes retail banking loan and credit risk data to understand loan performance, customer risk, and portfolio trends.

## Tools Used
- SQL
- Power BI
- Data Modeling
- Excel

## Key KPIs
- Approval Rate
- Default Rate
- Delinquency Rate
- Portfolio Exposure
- Collection Efficiency

## Key Analysis
- Loan performance analysis
- Customer risk analysis
- Default and delinquency analysis
- Portfolio monitoring
- Trend analysis

## Dashboard
Power BI dashboard provides interactive views of loan performance and credit risk metrics.
